# Low-level implementation map

Transport validation lives in `contracts.py`. API dependencies own transactions and finish them before HTTP response delivery. `services.py` receives a session and implements use cases; pure numerical functions live in `domain.py`. `db.py` defines current SQLAlchemy mappings and constructs a process-local pool with sessions scoped to transactions.

`worker.process` encloses inbox insertion and handler effects in a transaction. `messaging.relay_once` publishes committed outbox records and marks them sent only after confirmation. Consumer offsets advance after database commit. This combination tolerates redelivery without repeated business effects.

Normalization resolves accepted revisions at event-time boundaries. Aggregation recomputes the current contribution set under an asset lock rather than incrementing totals. Balance/evaluation fingerprints and archived evidence preserve correction history. Investigation updates lock and check the version before recording the actor and transition.

Public operations and parameter details are generated by FastAPI at `/openapi.json`; examples and limitations are in [api.md](api.md). Database details are in [database.md](database.md).
